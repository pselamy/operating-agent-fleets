# 3. Skills instead of a monolithic framework

## Reader question

How can capabilities and context propagate across an agent system without a monolithic orchestration framework?

## Chapter contract

This chapter will explain four capability tiers—agent-local, internal fleet, public fleet, and curated upstream—and how skills and MCP tools mediate access to systems of record. It will describe context routing as deliberate retrieval through durable, auditable substrates rather than direct mind-to-mind communication.

The chapter will examine why this system did not require LangChain, LangGraph, or a vector database as its organizing layer. It will also distinguish authoritative Markdown-in-Git knowledge from derived recall systems and proposed fleet-memory improvements.

## Required evidence before drafting

- Public lineage records for the agent-skills library, laneq, and relevant public MCP repositories.
- Public-safe examples of skill provenance, installation, and version propagation.
- Verified evidence for any claim about fleet-memory deployment or enforcement.

## Required visuals

- Skill and knowledge propagation flow.
- Cross-plane collaboration sequence with trust boundaries.

## Safety and accuracy boundary

Public examples will not expose private skills, agent endpoints, jump-host details, private repository names, access paths, credentials, or raw messages. The chapter will use **mediated coordination**, not peer-to-peer mesh or hive-mind language. Proposed memory or enforcement behavior will remain explicitly labeled until live evidence exists.
